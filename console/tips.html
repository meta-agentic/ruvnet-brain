RuvNet Brain · the guide

You don't have to learn the toolkit. That's the design.

The Brain looks like a lot of pieces — grounding, memory, gates, routing, skills. Here's the whole trick: it arranges itself around the way you already work. There are three depths of use, and the first one is doing nothing.

“I don't have to load 350 skills in Ruflo that 99% of which I never use. I can specifically learn and say that, for this particular task, I need a particular plugin or skill. And the system is smart enough to be able to say, okay, I've seen this before, therefore, I know that I need this particular skill to do this particular task.”

— rUv · hackerspace call, 2026-07-16 · sourced from the brain (ruv-meetings)

three depths 1 · do nothing — always on 2 · say it in plain English 3 · name the exact tool

the whole argument, in one picture

Same model. Same prompt. Everything around it.

rUv's lever isn't a smarter model — it's what wraps the one you already have. Plain Claude Code sends your prompt straight at an expensive model and takes whatever comes back. The harness grounds it, routes it to the cheapest model that can actually do the job, hands back what your project already decided, inspects the write before it lands, and checks it on the way out. You type the same thing either way.

Depth 1 · always on

It just works — do nothing

Type normally, like it's plain Claude. For most people, this is the whole product.

01
  • Grounded answers

    Any claim about rUv's tools is checked against his real source before it's asserted. No guessing.

  • Project memory

    Decisions from past sessions come back on their own as you work. You never re-explain the project.

  • Gates on every move

    A wired install runs a stack of gates that read each move before it lands — several can stop a bad one outright. Your console shows your real count, live.

Like a good spotter at the gym: silent on every rep, loud only when you're about to drop the bar.

depth 4 · the payoff

You're not learning a new tool. You're multiplying the ones you already pay for.

The learning curve is small — most of it is depth 1, which is doing nothing. The return is world-class output: grounded, cheaper, checked. It works the same whether you write code or just describe what you want.

04

What it doesn't ask of you

  • You don't have to master 20 separate tools — it knows which one this task needs.
  • You don't pay frontier prices for everything — it routes to the cheapest model that can do the job.
  • You don't have to be an expert — or even a coder.
  • You don't re-explain your project every session — it remembers.

What it gives you

  • Answers grounded in real source, not guesses.
  • The cheapest capable model on every task — the expensive one stays idle. 28.5% cheaper at 98.1% bar-compliance · ADR-076
  • Gates that inspect — and can refuse a bad write before it lands.
  • World-class AI apps — whether you write code or just describe what you want.
