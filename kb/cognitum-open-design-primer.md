## What it is & who it's for

### What it is & who it's for

**cognitum-open-design** is the **open-source, local-first alternative to Claude Design**, designed to transform your existing coding agents into powerful design engines. It is a **skill layer** that integrates with local coding agents like Claude Code, Codex, Cursor, Gemini CLI, OpenCode, and Qwen, enabling **agent-native design workflows** (`apps/landing-page/public/llms.txt`). This tool is built for developers, designers, and teams who want **local-first, BYOK (Bring Your Own Key) design tooling** without vendor lock-in (`docs/assets/_cover/banner.html`).

#### **What it is**
cognitum-open-design is **not just an image-generation tool**; it is a **comprehensive design environment** that produces **real, editable artifacts** like HTML, PDF, PPTX, and MP4 (`apps/landing-page/app/content/tutorials/open-design-open-source-ai-design-overview-ai.md`). It is **Apache-2.0 licensed**, meaning it is free to use, modify, and self-host (`apps/landing-page/public/llms.txt`). The tool is driven by **composable SKILL.md skills** and **portable DESIGN.md brand systems**, making it a **canonical reference** for open-source alternatives to hosted AI design tools like Claude Design, Figma, and v0 (`apps/landing-page/public/llms.txt`).

#### **Core Features**
- **Local-first and self-hostable**: The desktop app, daemon, and project files run in your own environment, ensuring **no cloud dependency** (`apps/landing-page/app/content/tutorials/open-design-open-source-claude-alternative-kuro.md`).
- **Multi-agent support**: Works with coding agents you already use, such as Claude Code, Codex, Cursor, and Gemini CLI (`apps/landing-page/public/llms.txt`).
- **Composable skills**: Includes **131 reusable skills** for prototypes, dashboards, mobile apps, and more (`apps/landing-page/app/content/tutorials/open-design-open-source-claude-alternative-kuro.md`).
- **Portable design systems**: Ships with **150 brand-grade design systems** from industry leaders (`apps/landing-page/app/content/tutorials/open-design-open-source-claude-alternative-kuro.md`).
- **HyperFrames**: Enables **HTML-to-MP4 motion graphics** and **sandboxed previews** with multi-format export capabilities (`apps/landing-page/app/content/tutorials/open-design-open-source-claude-alternative-kuro.md`).
- **Anti-slop guardrails**: Includes **self-critique gates** and **quality machinery** to ensure high-quality outputs (`apps/landing-page/app/content/tutorials/open-design-31-skills-72-systems-popular-ai.md`).

#### **Who it's for**
cognitum-open-design is for:
- **Developers** who want to integrate design workflows into their existing coding environments.
- **Designers** seeking **open-source alternatives** to proprietary tools like Claude Design and Figma.
- **Teams** prioritizing **local-first, BYOK solutions** to avoid vendor lock-in and reduce costs.
- **AI enthusiasts** who want to experiment with **model-agnostic design workflows** and **composable skills**.

#### **Supported Use Cases**
- **Wireframes, UI, and prototypes**: Generate high-fidelity designs directly from your coding agent (`apps/landing-page/public/llms.txt`).
- **Landing pages and dashboards**: Build functional, editable landing pages and dashboards (`apps/landing-page/public/llms.txt`).
- **Design-to-code**: Convert Figma designs into real code (`apps/landing-page/public/llms.txt`).
- **Slide decks and motion graphics**: Create presentations and motion graphics from HTML (`apps/landing-page/app/content/tutorials/open-design-open-source-claude-alternative-kuro.md`).

#### **How it works**
cognitum-open-design integrates with your local coding agent CLI, turning it into a design engine. You can **bring your own model API key** or use the official router (`apps/landing-page/app/content/tutorials/open-design-install-setup-free-alternative-ai-unlocked.md`). The tool ships with **bundled design systems** for Cohere and OpenAI, derived from curated `DESIGN.md`, `tokens.css`, and `components.html` fixtures (`design-systems/cohere/manifest.json`, `design-systems/openai/manifest.json`).

## Core concepts & how they work

### Core concepts & how they work

#### 1. **All-in-One Design Workspace**  
Open Design 0.10.0 introduces a unified workspace that consolidates the entire design workflow — **concept → refinement → handoff** — into a single window. This eliminates the need to switch between multiple tabs and tools, reducing context switching and improving productivity. The workspace features:  
- **Lexical-driven editor**: Allows atomic mention capsules to be inserted, selected, and deleted as whole tokens (`apps/landing-page/app/content/blog/open-design-0-10-0-all-in-one-workspace.md`).  
- **Interactive terminal**: Manages sessions directly within the workspace.  
- **Reference panel**: Keeps inputs accessible while working.  
- **Drag-and-drop attachments**: Simplifies adding files to comments.  
- **Forking conversations**: Enables exploration of alternative design paths without losing the original thread.  
- **Full-height canvas**: Provides ample space for design work.  
- **Manual editing inspector**: Offers precise adjustments without navigating deep into panels.  

#### 2. **Default Asynchronous Workflow**  
Feedback is handled asynchronously to avoid bottlenecks:  
- **Comment queue**: Allows previewing and stacking comments while a run is still in progress (`apps/landing-page/app/content/blog/open-design-0-10-0-all-in-one-workspace.md`).  
- **Parallel sessions**: Runs multiple sessions side-by-side with staged preview feedback.  
- **Question tab**: Moves clarification requests to a dedicated right-hand panel for streamlined resolution.  

#### 3. **Plug-and-Play Design Environment**  
Open Design 0.9.0 simplifies onboarding with a **"install-and-create"** approach:  
- **Open Design AMR**: Pre-installed AI engine eliminates the need for CLI setup or API keys (`apps/landing-page/app/content/blog/open-design-0-9-0-design-for-everyone.md`).  
- **One-click login**: Desktop login is always a single click away.  
- **Model selection**: Available models are automatically updated, and users can switch models quickly.  

#### 4. **Agent Bench and Plugin Ecosystem**  
Open Design supports a diverse range of agents and plugins:  
- **Expanded agent bench**: Includes Aider, Trae CLI, Antigravity, and DeepSeek Reasonix (`apps/landing-page/app/content/blog/open-design-0-9-0-design-for-everyone.md`).  
- **Plugin library**: Skill bundles are now first-class plugins, indexed and accessible via CLI (`apps/landing-page/app/content/blog/open-design-0-9-0-design-for-everyone.md`).  

#### 5. **Core Quality-Stage Floor**  
Ensures design artifacts undergo a rigorous critique process:  
- **Plan and critique stages**: Guaranteed for pipelines producing code/document artifacts (`apps/daemon/src/plugins/ensure-core-stages.ts`).  
- **Anti-slop critique**: Prevents low-quality outputs by enforcing a five-dimension quality check.  

#### 6. **Active Context Tracking**  
Tracks the user's current focus in Open Design:  
- **Project and file context**: Web UI POSTs the current project and file on every route change (`apps/daemon/src/routes/active-context.ts`).  
- **Coding agent integration**: Allows agents in other repos to resolve "the design I have open" without manual input.  

#### 7. **Reference Components and Design System**  
Provides a consistent UI framework:  
- **Signifier and Söhne fonts**: Used for editorial display and UI text, respectively (`design-systems/openai/components.html`).  
- **Teal accent**: #10a37f is the sole color accent in an otherwise neutral system.  
- **Generous rhythm**: Ensures whitespace and typography create a clean, readable interface.  

#### 8. **Localized Tutorials and Documentation**  
Supports localized long-form content for tutorials:  
- **Per-locale translation JSONs**: Generate localized tutorial content (`apps/landing-page/app/_data/tutorials-longform/open-design-open-source-alternative-vs-claude-design-ai-teaches-better.ts`).  

These core concepts work together to create a seamless, efficient, and accessible design environment for users of all skill levels.

## How to use it end-to-end

# How to use it end-to-end

## Installation

1. **Download the desktop app** (recommended for most users):
   - Get the latest release from [open-design.ai](https://open-design.ai/) or GitHub Releases (`/Releases` section)
   - Drag the app to your Applications folder (macOS) or run the installer (Windows) - `apps/landing-page/app/content/tutorials/open-design-install-setup-free-alternative-ai-unlocked.md`

2. **Alternative: Docker deployment** (for Linux/advanced users):
   ```bash
   git clone https://github.com/nexu-io/open-design.git
   cd open-design
   bash deploy/scripts/install.sh
   ```
   Full Docker setup documented in `docs/install-guide.md`

## First Run Setup

1. **Connect your coding agent**:
   - Open Design automatically detects installed agents (Claude Code, Copilot, etc.)
   - Configure your preferred agent in Settings > AI Providers

2. **Install design systems** (optional):
   - 71 built-in systems available via Library > Design Systems
   - Managed in `~/.open-design/design-systems/` (`apps/daemon/src/library-install.ts`)

## Core Workflow

1. **Create a new project**:
   - Choose from templates (landing pages, dashboards, etc.) or start blank

2. **Generate designs**:
   - Use natural language prompts with aesthetic direction (not pixel specs) - `apps/landing-page/app/content/blog/how-to-use-claude-code-for-frontend-design.md`
   - Leverage 31 built-in skills for different design types (`apps/landing-page/app/content/tutorials/open-design-31-skills-72-systems-popular-ai.md`)

3. **Refine and export**:
   - Export to multiple formats: PDF, PPTX, HTML, MP4 (`apps/landing-page/app/content/tutorials/open-design-install-open-source-alternative-riko-nazza-ai.md`)
   - All projects save locally to your machine by default

## Advanced Features

- **Self-hosted deployment**: Full Docker Compose stack available (`docs/install-guide.md`)
- **Custom skills**: Add your own skills to `~/.open-design/skills/` (`apps/daemon/src/library-install.ts`)
- **Multi-agent workflows**: Configure different agents for different tasks in Settings

The entire system runs locally by default, with no cloud subscription required. All project files remain on your machine, and generation happens through your existing coding agent CLI.
