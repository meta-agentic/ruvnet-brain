Ruflo's Architecture Decision Records (ADRs) are stored in the directory located at `v3/implementation/adrs/v3-adrs.md`. This document outlines various architectural decisions made by the Architecture Team for the Claude-Flow v3 project, which began on January 3, 2026. The ADRs cover a range of topics, including foundational architecture, design structures, and security features.

The specific areas covered by these ADRs include:

1. **Core Architecture Decisions**: For example, ADR-001 discusses adopting agentic-flow as the core foundation, which is currently proposed, while several other ADRs (e.g., ADR-002 to ADR-014) have been implemented, addressing aspects like Domain-Driven Design, plugin-based architecture, and security features.

2. **Implementation of Features**: The ADRs detail the implementation of various features such as the Unified Memory Service (ADR-006), Event Sourcing for State Changes (ADR-007), and the LLM Provider System (ADR-011).

3. **Security and Compliance**: Security features are also a significant focus, with multiple ADRs (e.g., ADR-012 and ADR-013) dedicated to enhancing security within the system.

For further details on the specific decisions and their statuses, you can refer to the ADR index in the same document at `v3/implementation/adrs/v3-adrs.md`.
