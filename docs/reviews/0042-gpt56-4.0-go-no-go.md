## The question
The owner is pushing to stamp 4.0 now ("why don't we just move the whole thing to 4.0"). Is that an
honest major-version release, or a version-number stunt? What may the "What's new in 4.0" honestly claim?

## Verdict: **HOLD** (GPT-5.6), and I **ACCEPT** it.

The refutation is not an outside opinion overriding the owner — it enforces **ADR-042 (Accepted,
authored by Stuart, 2026-07-23)**, which states 4.0 stays `3.9.x-dev` until verified because "a premature
`4.0.0` would be the exact thing this project forbids — a bigger number standing in for work that is not
done." ADR-042's checklist items 1–3 are unmet: L3–L5 not verified (still L2), precision/latency are
deploy-gated on real use (advocacy ledger = **0 lines**), and there is no independent re-grade of a 4.0
build.
