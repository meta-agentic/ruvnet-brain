## 6. What must happen for an honest 4.0 — shortest ordered list

**0. Get the suite green again — today, before any of the below** (E11). `explainer/index.html` claims
"What's new in 4.0" against a 3.5.x product, and `narrative-version.test.mjs` is red because of it.
Revert the explainer to 3.5 until 4.0 actually ships. **It is item 0 rather than item 1 because it is
not 4.0 work at all** — it is a live public page making a claim the rest of this document disproves,
and it is the cheapest fix on the list. Owned by the parallel swarm; not fixed here.

Ordered by dependency, not by effort. Each item unblocks the ones below it; nothing here is optional
and nothing here is padding.

1. **Make `npm test` fail honestly on a cold model cache** (E2/E2b). Both suites pass on the committed
   tree, so this is not a blocker — it is first because it is an hour's work and it currently mislabels
   a healthy brain as a broken one. On a fresh machine the battery prints `(no hit)` on every question
   (8 observed), indistinguishable from a retrieval outage. Detect the cold cache and say so, or default
   `KB_MODEL_CACHE`. **Empty-first is a house rule, and this is the one place the test surface violates
   it.**

2. **Reconcile the release channels** (E8, ask #9). Tag and cut a GitHub release matching what npm
   already has. Plugin users are a full minor behind *right now*; every claim made to them is wrong
   until this lands.

3. **Build the ground-truth fixture machine** (ADR-028 #2). ADR-028 names it "the first build item,
   because without it every subsequent number is unfalsifiable." Recall and false-alarm rate — the
   latter a non-negotiable 0 — are unmeasurable without it, and **0 of the 5 acceptance metrics are
   instrumented today.** No fixture, no grade; no grade, no 4.0.

4. **Wire the offensive audit to an in-session surface** (E9 → L3). One consumer for
   `capability-audit.mjs` that speaks without the user opening a page, with a one-action permanent
   silence. This single change moves the ladder L2 → L3 and is the largest value-per-line in the list.
